# Recettes

Nos recettes favorites, classées par catégorie.

Chaque fiche contient :
- **Original** : la source et la recette originale (jamais modifiée).
- **Modifications** : les ajustements proposés ou adoptés, datés.
- **Notes** : ce qu'on en pense, qui aime quoi, les variantes.
- **Historique** : les dates où la recette a été cuisinée.
